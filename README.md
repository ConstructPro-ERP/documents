## Project Description

This repository contains the project documentation for the **ConstructPro ERP** system, including the Software Requirements Specification (SRS), Software Design Specification (SDS), Architectural Decision Records (ADRs), and meeting notes.

**Broader Project:** [ConstructPro ERP Organization](https://github.com/ConstructPro-ERP)

## Prerequisites

- PDF Viewer or Markdown reader

## Installation & Run Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ConstructPro-ERP/documents.git
   cd documents
   ```
2. **View documents:**
   Browse the Markdown files or open the PDF files directly.
